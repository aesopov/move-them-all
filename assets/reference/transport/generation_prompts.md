# Pipes and teleports

Generated with built-in image_gen, based on prompts/05_pipes_teleports.md and assets/reference/master_style.png. Source sheets are preserved here. Run `bash tools/prepare_transport_assets.sh` to rebuild five transparent 128x128 sprites. The renderer uses the mouth sprite with existing directional arrows and pair colors. The teleport uses a tintable base and independently rotating swirl. Unlinked pads use a grey base without swirl. Straight and elbow sprites are supplied for future decorative pipe runs; the current mechanic draws only mouths.
