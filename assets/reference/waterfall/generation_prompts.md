# Waterfall Cliffs: shared art for levels 11–20

Generated using the jungle wall and floor sprites as style references. Assets load through the existing `waterfall` theme; no per-level image duplication is needed.

## background

Runtime asset: `assets/backgrounds/waterfall.png`

Wide landscape 16:9 game background. Misty waterfall cliffs with cascading white water on BOTH outer edges, blue-grey rocks, distant pale turquoise gorge, sparse ferns on foreground corners. Quiet dark teal center behind a puzzle board; no board, UI, text, characters. Hand-painted polished casual game illustration, soft light, depth and atmospheric mist. Full bleed opaque landscape.
