# Modular stone and scenery kit

Generated with built-in image_gen using the Jungle wall as a style reference.
Original images are retained; runtime imports are limited to 256 pixels per cell (512 for two-cell assets).
Prompts and provenance: `prompts/terrain_kit.json`.

| Asset | Footprint in cells |
| --- | --- |
| slab_1x05 | 1 × 0.5 |
| slab_2x05 | 2 × 0.5 |
| corner_cut | 1 × 1, upper-right 0.5 × 0.5 quarter missing |
| fallen_log | 2 × 1 |
| broken_column | 1 × 1 |
| rubble | 1 × 1 |

Add a Node2D with `scripts/game/decor_terrain.gd` beneath a LevelDecor root.
Choose the asset and footprint; position uses 64 pixels per cell, so a half-cell
offset is 32 pixels. Quarter turns rotate around the footprint centre. Transparent
outer padding is ignored during rendering so artwork fills the chosen footprint.
The notch remains transparent. These nodes are scenery only: they do not create
collision. No campaign layouts or collision rules have been changed.

Preview: `assets/reference/terrain_kit/preview.png`, generated by
`godot --path . --script tools/preview_terrain_kit.gd`.

## Wall-mounted support

`support_platform.png` — a wooden shelf with a left mounting post and diagonal brace, 2×1 cells. Transparent background; generated with the built-in image tool using `prompts/jungle_support_platform.txt`. In the designer, use **Flip horizontally** to attach it to a right wall. Visual decoration only; paint invisible obstacle cells separately for collision.
